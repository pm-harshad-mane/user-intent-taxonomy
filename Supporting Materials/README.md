# Supporting Materials

This folder preserves background, presentation, and workbook material that supports the proposal but is not itself part of the candidate normative taxonomy package.

These files are retained so reviewers can see how the proposal evolved, how the story can be explained to non-implementers, and what source material informed the current structure.

The current candidate normative artifacts are the TSV files under `../User Intent Taxonomies/`.

The current proposal-facing explanatory documents live at the repository root:

- `../README.md`
- `../proposal.md`
- `../implementation.md`
- `../feedback.md`

Some files in this folder were authored before the repository was restructured and may reference earlier file names or paths. Where possible, newer supporting copies have been added rather than deleting the original material.

## Files

- `User_Intent_Taxonomy_Overview.pdf`
- `project_brief.md`
- `notebooklm_storyboard_input.md`
- `notebooklm_storyboard_input_2.md`
- `user_intent_taxonomy_framework_v0_3_master.xlsx`

## Notes on use

- `project_brief.md` is the updated short-form narrative summary of the current proposal package.
- `notebooklm_storyboard_input.md` is the original storyboard-oriented narrative.
- `notebooklm_storyboard_input_2.md` is the updated storyboard input aligned to the restructured repository and current proposal language.
- The PDF and workbook are retained as supporting background and presentation artifacts.

Reviewers evaluating the proposal itself should start with the root-level files first and use this folder as supplementary context.
