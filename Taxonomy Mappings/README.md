# Taxonomy Mappings

This folder contains mapping assets for connecting the proposed User Intent Taxonomies to external standards and internal schemas.

## Files

- `User Intent Taxonomy 1.0 - External Mapping Template.tsv`
- `User Intent Taxonomy 1.0 - Mapping Principles.md`
- `User Intent Taxonomy 1.0 to IAB Content Taxonomy 3.1.tsv`
- `User Intent Taxonomy 1.0 to IAB Audience Taxonomy 1.1.tsv`
- `User Intent Taxonomy 1.0 to IAB Ad Product Taxonomy 2.0.tsv`

## How to read the first-pass mappings

These mapping files are deliberately conservative.

- `Direct` means the IAB taxonomy appears to cover substantially the same topical or product concept.
- `Adjacent` means there is overlap, but the user intent concept is not equivalent to the IAB taxonomy concept.
- `No direct equivalent` means the proposed User Intent taxonomy is capturing something not standardized in the target IAB taxonomy.

Each file includes:

- candidate IDs where they are reasonably clear
- candidate names
- confidence and review status
- notes describing the reasoning and any validation still needed

## Intended future contents

- User Intent to IAB Content mappings
- User Intent to IAB Audience mappings

The current mapping file is a template so that external alignment can be reviewed without changing the normative taxonomy files.
